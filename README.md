# 📊 Projeto FinancePy - Análise de Margem de Contribuição

Este projeto utiliza **Python** e a biblioteca **Pandas** para automatizar a análise financeira de vendas mensais. O objetivo é fornecer uma visão estratégica rápida sobre a eficiência de cada categoria de produto.

## 🚀 Funcionalidades
- **Cálculo Automático:** Margem de Contribuição Nominal (R$) e Percentual (%).
- **Visão Gerencial:** Agrupamento por categoria com soma de lucros e média de eficiência.
- **Exportação:** Geração de um relatório estratégico em Excel (`.xlsx`) pronto para apresentação.
- **Tomada de Decisão:** Identificação de categorias com alto volume vs. categorias com alta margem.

## 🛠️ Tecnologias Utilizadas
- Python 3.x
- Pandas (Manipulação de dados)
- Openpyxl (Integração com Excel)

## 📋 Como executar
1. Certifique-se de ter o arquivo `vendas_mensais.xlsx` na raiz do projeto.
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute o script: `python main.py`
